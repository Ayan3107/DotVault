# DotVault

> A personal knowledge vault for saving, organizing, and quickly finding developer knowledge.

🔗 **Live App:** https://dotvault.onrender.com

---

## About

DotVault is a lightweight developer knowledge vault designed to keep useful technical information in one place.

Instead of keeping commands, API references, notes, links, and small pieces of technical knowledge scattered across files and browser tabs, DotVault provides a single searchable interface for storing them.

Each item can contain:

- A title
- Detailed content
- A category
- Multiple tags
- A unique ID
- A creation timestamp

The application provides a simple interface for adding and searching knowledge while keeping the underlying architecture small and easy to understand.

---

## Features

### 📚 Knowledge Storage

Create and store personal knowledge items with:

- Title
- Content
- Category
- Tags

### 🔎 Search

Search across the vault to quickly find previously saved information.

### 🗂️ Categories

Items can be organized into:

- Commands
- Notes
- APIs
- Links

### 🏷️ Tags

Add multiple tags to an item for additional organization.

Example:

```text
python, git, terminal
